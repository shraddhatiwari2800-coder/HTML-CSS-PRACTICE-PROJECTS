# My Food - HTML/CSS Practice Project

## About

This project was created for learning and practicing HTML and CSS.

The design is inspired by the W3Schools "My Food" template and was recreated as a frontend development exercise. The goal was to practice:

* HTML page structure
* CSS styling
* Flexbox layouts
* Responsive design
* Working with images and cards

## Technologies Used

* HTML5
* CSS3

## Purpose

This project is intended for educational and portfolio purposes only.
